Your data

Tried foods, reactions and notes are stored on this phone only, in the app's own storage. App updates never touch them, but they are gone if you delete the app icon, clear Safari's website data, or switch phones. Keep a backup in one of the two ways below.

1 · Backup file

Export writes everything to a small JSON file you keep somewhere safe (Files, iCloud, email to yourself). Import loads such a file back and replaces what is on this phone.

2 · Automatic backup to GitHub

Every change is copied within seconds to a secret Gist in your GitHub account, and a new phone (or this one after a reinstall) gets everything back as soon as you connect it. The Gist is unlisted and not searchable, but anyone who has its link could read it.

To connect: on github.com open Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, tick only the gist scope, copy the token and paste it here. It stays on this phone and is not included in export files.
